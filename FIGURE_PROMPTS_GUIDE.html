Figure 3.3 — Image Diagnosis Pipeline
📍 Chapter 3 › 3.4 Image Diagnosis Pipeline 🛠 Mermaid Flowchart
Mermaid (recommended)
flowchart TB
  U[User uploads image] --> V{Valid?
size ≤ 10MB, type ok}
  V -- No --> E[Return error message]
  V -- Yes --> TMP[Save to temp file]
  TMP --> PRE[Load 224x224, model rescales]
  PRE --> CNN[MobileNetV2 CNN predict]
  CNN --> CONF[Disease + confidence score]
  CONF --> LOW{Confidence low?}
  LOW -- Yes --> WARN[Add 'verify with vet' warning]
  LOW -- No --> GEM[Fetch guidance from Gemini]
  WARN --> GEM
  GEM --> SAVE[(Save AnimalDetection record)]
  SAVE --> RPT[Return report to frontend]

📍 Chapter 4 › 4.6.1 JWT Token Flow 🛠 Mermaid (sequence) Sequence diagram
Mermaid (recommended)
sequenceDiagram
  participant U as User
  participant F as React Frontend
  participant B as Django + SimpleJWT
  participant D as MySQL
  U->>F: Enter username + password
  F->>B: POST /api/token/
  B->>D: Verify credentials
  D-->>B: User OK
  B-->>F: access (24h) + refresh (7d)

  Note over F,B: For every protected request
  F->>B: Request + Authorization: Bearer access

  B-->>F: 200 data  (or 401 if expired)
  F->>F: On 401 → clear token, go to /signin
Figure 5.1 — Confidence Distribution Across Sample Predictions
📍 Chapter 5 › 5.5 Reliability (after the table) 🛠 Excel / matplotlib / real dashboard Bar chart
Behtareen: apne real data se banayein. Agar real numbers nahi hain to neeche sample data se chart bana lein (Excel mein paste karke bar chart). Aap chahein to apne app ke dashboard ka pie/area chart bhi screenshot le sakte hain.
Python (matplotlib) — sample, real values se replace karein
import matplotlib.pyplot as plt
diseases = ['Foot & Mouth', 'Lumpy Skin', 'Healthy']
confidence = [0.93, 0.90, 0.96]   # apne real averages daalein
plt.bar(diseases, [c*100 for c in confidence], color=['#2563eb','#7c3aed','#059669'])
plt.ylabel('Average confidence (%)'); plt.ylim(0,100)
plt.title('Prediction confidence by class')
plt.savefig('fig5_1.png', dpi=200, bbox_inches='tight')

✅ Word mein figure kaise daalein

  1. Tool se figure ko PNG (ya SVG) export karein.
  2. Word mein report kholein → us figure ka [ Insert figure / diagram here ] placeholder line dhoondein.
  3. Placeholder ki italic line ko select karke delete karein.
  4. Usi jagah Insert → Pictures se apni image daal dein. Niche jo bold caption (Figure X.Y: ...) pehle se hai usay rehne dein.
  5. Image ko center karein aur width ~6 inch rakhein taa-ke margins ke andar fit ho.
