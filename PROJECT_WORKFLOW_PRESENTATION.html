1. Project Ek Nazar Mein

VetAI Diagnostics ek website hai jo gaaye/maweshi (cattle) ki bimari pakarne mein madad karti hai. Do tareeqon se:

  • Tasveer se (Image): User gaaye ki photo upload karta hai → ek AI model (CNN) batata hai bimari kaun si hai (Foot-and-Mouth, Lumpy Skin, ya Healthy) aur kitni yaqeen (confidence) ke saath.
  • Alamaat se (Symptoms): User bimari ki alamaat select karta hai → system top 5 mumkin bimariyan rank karke dikhata hai.

Phir dono soorton mein Google Gemini AI se live medical maloomaat (ilaaj, bachaav, dawaiyan, severity) mangwa kar report banti hai. Ek Vet AI Chatbot bhi hai jisse user animal health ke sawal pooch sakta hai.

Aasaan misaal: Jaise insaan ke liye "symptom checker" app hota hai — yeh wohi cheez hai magar gaaye ke liye, aur isme tasveer se bhi bimari pehchaani jaati hai.

3. User Ka Poora Safar (Step by Step)

1

Sign Up — Naya Account Banana

User username, email aur password daal kar account banata hai.

Andar kya hota hai: Form react-hook-form se banta hai → axios data ko backend ke POST /api/register/ par bhejta hai → Django ka RegisterView use ko create_user() se banata hai → password hash (encrypt) ho kar MySQL database mein save hota hai (plain password kabhi store nahi hota).
2

Sign In — Login Karna

User username + password daalta hai. Sahi hone par andar aa jaata hai.

Andar kya hota hai: axios → POST /api/token/ → SimpleJWT library username/password check karti hai → sahi hone par 2 tokens deti hai: access (24 ghante chalta hai) aur refresh (7 din). Yeh tokens browser ke localStorage mein save ho jaate hain. Token ek "digital pass" hai jo sabit karta hai ke aap login ho.
3

Protected Page — Bina Login Andar Nahi

Agar koi bina login ke main page kholne ki koshish kare to use seedha login page par bhej diya jaata hai.

Andar kya hota hai: ProtectedRoute (react-router-dom) check karta hai ke localStorage mein token hai ya nahi. Token na ho → Navigate se /signin par redirect.
4

Dashboard — Sab Features Ka Ghar

Login ke baad user ko ek tabbed dashboard dikhta hai: Dashboard, Image Diagnosis, Symptom Diagnosis, Results, History, Vet Chat. Sidebar se feature switch hota hai.

Andar kya hota hai: Home.jsx tabs ko sambhalta hai (useState). Dashboard khulte hi axios se /statistics/ aur /history/ ek saath mangwaye jaate hain aur recharts se charts ban jaate hain.
5

Koi Feature Use Karna (jaise Image Diagnosis)

User photo upload karta hai → "Analyze" dabata hai → kuch second mein report aa jaati hai.

Andar kya hota hai: Har request ke saath axios Authorization: Bearer <token> header bhejta hai → backend JWTAuthentication token check karta hai → pata chalta hai yeh kaun sa user hai → AI chalti hai → Gemini se maloomaat → report wapas → screen pe dikh jaati hai.
6

Logout / Token Expire

User logout kare to token mit jaata hai. Ya token purana (expire) ho jaye to system khud login page par bhej deta hai.

Andar kya hota hai: Logout par localStorage se token remove. Agar backend 401 Unauthorized de (token invalid/expired) to frontend token clear karke /signin par redirect kar deta hai.

4. Authentication — Konsi Libraries, Kya Kaam

Authentication ka matlab: "yeh sabit karna ke user kaun hai aur usay andar aane ki ijaazat hai ya nahi." Is project mein JWT (JSON Web Token) tareeqa use hua hai. Niche har library aur uska kaam asaan zubaan mein:

Library / ToolKaam (asaan zubaan)Kahan Use Hua
djangorestframework-simplejwt (backend) Login par token (digital pass) banata hai aur har request par check karta hai ke pass asli hai ya nahi. Access token 24 ghante, refresh token 7 din. settings.py (SIMPLE_JWT config), server/urls.py (/api/token/, /api/token/refresh/)
Django built-in auth (backend) User model, password ko hash (mehfooz) karna, create_user(). Plain password kabhi save nahi hota. accounts/serializers.py (create_user), accounts/views.py (RegisterView)
Django REST Framework — JWTAuthentication Har protected API request par token parh kar user pehchanta hai (request.user). Token galat ho to 401 deta hai. settings.py (DEFAULT_AUTHENTICATION_CLASSES), har view mein permission_classes=[IsAuthenticated]
react-router-dom (frontend) Pages ke darmiyan navigation + ProtectedRoute (bina login page block karna). App.jsx (routes), ProtectedRoute.jsx (token guard), SignIn.jsx (redirect)
axios (frontend) Backend ko request bhejta hai aur har baar Authorization: Bearer <token> header lagata hai. Har component jahan API call hai (SignIn, SignUp, Dashboard, ImageDiagnosis, ...)
browser localStorage Token ko browser mein mehfooz rakhta hai taa-ke page refresh ke baad bhi user login raha rahe. SignIn.jsx (save token), config/api.js (read token), LogOut (remove)
jwt-decode (frontend) Token ke andar ki maloomaat (jaise expiry, username) parhne ke liye — bina server ke. Project mein available hai token handle karne ke liye. Frontend dependency (package.json)
react-hook-form (frontend) Login/Signup forms banana + validation (jaise "password 8 character ka ho"). SignIn.jsx, SignUp.jsx
django-cors-headers (backend) Frontend (alag domain) ko backend se baat karne ki ijaazat deta hai — warna browser block kar deta. settings.py (MIDDLEWARE + CORS_ALLOWED_ORIGINS)

Authentication Ka Flow — Ek Tasveer Mein

SIGN UP: Form ─axios POST /api/register/─▶ Django create_user() ─▶ password HASH ─▶ MySQL SIGN IN: Form ─axios POST /api/token/─▶ SimpleJWT (check user+pass) ─▶ { access, refresh } │ browser localStorage mein save HAR REQUEST: axios ── Authorization: Bearer <access> ──▶ JWTAuthentication ─▶ "yeh user X hai" │ token galat/purana ─▶ 401 ─▶ frontend logout + /signin
Aasaan tashreeh (token kyun?): Har baar password bhejne ke bajaye, login par ek "pass" (token) mil jaata hai. Aage har kaam mein wohi pass dikhaya jaata hai. Yeh tez bhi hai aur mehfooz bhi — password baar baar network par nahi jaata.

5. Har Feature — Layman Explanation

📷 Feature 1 — Image Diagnosis (Tasveer se bimari)

User kya karta hai: Gaaye ki photo upload karta hai aur "Analyze" dabata hai.

Hota kya hai (asaan): Ek trained AI model photo dekh kar batata hai bimari kaun si hai aur kitni confidence (% mein). Phir Gemini AI se uska ilaaj/bachaav mangwa kar report banti hai.

Behind the scenes: Photo → backend /api/animal/detect/ → TensorFlow ka MobileNetV2 CNN model prediction karta hai → Gemini API se live maloomaat → record MySQL mein save → report screen par.

react-hook-formaxiosreact-query TensorFlow / KerasPillow + numpyGemini API

🩺 Feature 2 — Symptom Diagnosis (Alamaat se bimari)

User kya karta hai: Ek list mein se alamaat (jaise bukhar, langra-pan, bhook na lagna) select karta hai.

Hota kya hai (asaan): System har bimari se in alamaat ka milaan karta hai aur top 5 sab se mumkin bimariyan, score ke saath, dikhata hai. Best match ke liye Gemini se ilaaj bhi aata hai.

Behind the scenes: Alamaat → /api/diagnose/ → pandas ek CSV dataset (~2000 records, ~93 alamaat) parh kar scoring karta hai (confidence = 0.6×match + 0.4×coverage) → best match Gemini se enrich → save.

react-hook-formreact-query (useQuery)axios pandasGemini API

📋 Feature 3 — Diagnosis Results (Report)

User kya karta hai: Diagnosis ke baad ek saaf-suthri "medical report" dekhta hai.

Hota kya hai (asaan): Severity (kitni khatarnak), symptoms, ilaaj ke steps, bachaav, recommended dawaiyan, aur agar bimari chhoot wali (contagious) ho to laal warning.

Behind the scenes: Agar kisi field ka data missing ho to component khud /api/diseases/<id>/ se baqi maloomaat mangwa leta hai.

lucide-react (icons)axiosTailwind CSS

💬 Feature 4 — Vet AI Chat (Sawal-jawab bot)

User kya karta hai: Animal health ke baare mein chat mein sawal poochta hai (jaise "bimari ki aam alamaat kya hain?").

Hota kya hai (asaan): Ek AI assistant veterinary andaaz mein jawab deta hai. Purani baat-cheet browser mein yaad rehti hai.

Behind the scenes: Message → /api/animal/vetchat/ → backend ek "veterinary system prompt" ke saath Gemini API ko bhejta hai (API key chhupi rehti hai server par). Chat history localStorage mein save.

axiosrequests (backend)Gemini APIlocalStorage

📊 Feature 5 — Dashboard (Charts & Stats)

User kya karta hai: Apne saare scans ka khulasa graphs mein dekhta hai.

Hota kya hai (asaan): Total scans, average confidence, kaun si bimari kitni baar aayi (pie chart), severity breakdown, aur recent activity.

Behind the scenes: /statistics/ + /history/ se data → recharts se charts ban jaate hain.

recharts (charts)axioslucide-react

📂 Feature 6 — Detection / Medical History

User kya karta hai: Apne puraane diagnoses ki list dekhta hai aur kisi bhi record ki detail khol sakta hai.

Hota kya hai (asaan): Sab records date ke hisaab se (naya pehle) dikhte hain. Sirf usi user ke records (har user ka data alag/mehfooz).

Behind the scenes: /api/animal/history/ sirf request.user ke records laata hai.

axiosDjango ORMMySQL

7. Frontend ↔ Backend Baat-cheet Kaise Hoti Hai

Frontend aur Backend do alag programs hain. Beech mein API (HTTP requests) se baat hoti hai — jaise restaurant mein waiter (axios) customer (frontend) ka order kitchen (backend) tak le jaata hai aur khana (data) wapas laata hai.

FRONTEND (React) BACKEND (Django) ───────────────── ───────────────── axios.post("/api/animal/detect/", photo) ──▶ view: image lo, AI chalao + header: Bearer <token> Gemini se info lo, DB mein save │ report screen pe dikhao ◀────── JSON { disease, confidence, treatment... }
  • Request: frontend axios se data + token bhejta hai.
  • Auth check: backend token verify karta hai (user kaun).
  • Kaam: backend AI/database/Gemini chalata hai.
  • Response: backend JSON mein jawab deta hai → frontend usay screen par dikhata hai.
